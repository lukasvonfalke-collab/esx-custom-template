# ESX Custom Template - Quick Overview

Dieses Release-Branch enthält ein Install-Template, mit dem du den Server schnell einrichten kannst.

Enthalten:
- core/ (dynamisches Fraktionssystem)
- police/ (MDT MVP, Arrests, Jail)
- database/*.sql (Schemas)
- server.cfg.example
- docs/INSTALL_FULL.md
- scripts/import_db.sh

Empfehlung: Bearbeite server.cfg.example bevor du den Server startest.

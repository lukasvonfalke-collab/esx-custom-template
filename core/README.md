# ESX Custom Template - Core

Dieses Repo enthält die Core-Resource für ein ESX-basiertes FiveM Roleplay Template mit dynamischen Fraktionen.

Install:
1. ensure oxmysql
2. ensure es_extended
3. place the 'core' resource into your resources folder
4. set mysql_connection_string in server.cfg
5. import database/schema.sql and database/seed_factions.sql
6. start server and set initial faction heads via DB or admin command
